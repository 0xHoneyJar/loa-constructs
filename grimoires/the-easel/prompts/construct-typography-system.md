## The Existing System (what we have)

Four voices, established in TDR-003 (rektdrop) and inherited by explorer:

| Voice | Font | Role |
|-------|------|------|
| **Display** | Basement Grotesque Black | Page titles, construct names — ALWAYS uppercase, tracking-display (0.02em) |
| **Data** | Geist Mono | Everything else — terminal readouts, body, labels |
| **Authority** | IBM Plex Serif | Rare — ritual declarations, the Loa's voice |
| **Annotation** | Noto Sans JP | Japanese texture layer, atmospheric |

**Critical constraint (TDR-005)**: Mark stroke weight = 1.5px at 160px to match Basement Grotesque Bold optical weight.

**The tier logos already prove the pattern**: Console Cowboy's distressed condensed ≠ Tessier's clean serif ≠ Panther Modern's bold block ≠ Wintermute's spaced thin. Each mark has its own type. The constructs need the same.

## Typography Registers for Sci-Fi Logomarks

From the deep research — each register carries a specific emotional signal:

### 1. CONDENSED GROTESQUE — "The Sprawl"
**Signal**: Density, urgency, Neo-Tokyo vertical pressure. Information crammed into tight space.
**Fonts**: Schmalfette Grotesk, Agency FB, Compacta, Dharma Gothic, Knockout
**Treatment**: Tight tracking, tall letterforms, stacked lines
**Best for constructs that**: move fast, process density, operate under pressure
**Tier precedent**: Console Cowboy (distressed variant)

### 2. EXTENDED SANS — "The Institution"
**Signal**: Space-age authority, hardware labels, institutional confidence. The typography of things that were built to last.
**Fonts**: Eurostile Extended, Microgramma Extended, Wide Latin, Orbit
**Treatment**: Wide tracking (0.2-0.4em), all caps, horizontal dominance
**Best for constructs that**: govern, standardize, provide infrastructure
**Tier precedent**: Wintermute (spaced thin)

### 3. GEOMETRIC SANS — "The Machine"
**Signal**: Mathematical precision, utopian void, clean systems. Technology that's invisible because it works.
**Fonts**: Futura, Avenir, Proxima Nova, GT America, Brandon Grotesque
**Treatment**: Even weight, optical perfection, medium tracking
**Best for constructs that**: compute, measure, optimize
**Tier precedent**: Tessier (clean geometric)

### 4. NEO-GROTESQUE — "The Engineer"
**Signal**: Professional depth, Swiss rigor, the design-engineer aesthetic. Invisible until you look closely.
**Fonts**: Söhne (Klim), ABC Diatype (Dinamo), Geist (Vercel), Untitled Sans (Klim), Apercu (Colophon)
**Treatment**: Subtle ink traps, optical sizing, tabular figures
**Best for constructs that**: build systems, define standards, work precisely

### 5. INKTRAP BRUTALIST — "The Bazaar"
**Signal**: Muscular, industrial, "someone is home." Deliberate imperfection as authenticity signal.
**Fonts**: Basement Grotesque, ABC Favorit (Dinamo), Druk (Commercial Type), GT Flexa (Grilli)
**Treatment**: Exaggerated ink traps, tight setting, heavy weight
**Best for constructs that**: create, forge, make things with force
**Tier precedent**: Panther Modern (bold block)

### 6. HIGH-CONTRAST SERIF — "The Ghost"
**Signal**: Old-world soul trapped in digital shell. History, authority, the human element. (Teruhisa Tajima's GITS insight: serif = the ghost, sans = the shell.)
**Fonts**: Bodoni, Didot, Freight Display, Ogg, Canela
**Treatment**: Extreme thick/thin contrast, elegant spacing, mixed case possible
**Best for constructs that**: hold knowledge, speak with ancient authority, preserve

### 7. STENCIL / MILITARY — "The Field"
**Signal**: Stamped, deployed, field-grade. The "A-frame erasure" — removing crossbars signals futurity.
**Fonts**: Stencil, Caslon Stencil, Halyard Stencil, PF Din Stencil, Knockout Stencil
**Treatment**: Broken letterforms, industrial marking, all caps
**Best for constructs that**: test, harden, secure, deploy

### 8. MONOSPACE TECHNICAL — "The Terminal"
**Signal**: Raw data, hacker culture, under-the-hood depth. The machine speaks.
**Fonts**: OCR-A, OCR-B, Fira Code, IBM Plex Mono, JetBrains Mono, Source Code Pro
**Treatment**: Fixed-width, dense setting, code-like
**Best for constructs that**: process data, run protocols, execute

### 9. DISPLAY CUSTOM — "The Artifact"
**Signal**: One-of-a-kind. The logo that could only belong to this construct.
**Fonts**: Custom lettering, modified existing faces, hand-drawn → vectorized
**Treatment**: Unique per construct, not reusable
**Best for constructs that**: have the strongest individual identity

## The Lockup System

### Mark + Type Spatial Rules

From the mark-type lockup research:

```
┌─────────────────────────────────────────┐
│                                         │
│    ┌──────────┐                         │
│    │          │    CONSTRUCT NAME        │
│    │   MARK   │    one-line descriptor   │
│    │          │                          │
│    └──────────┘                         │
│                                         │
└─────────────────────────────────────────┘

Clear space = 1x unit (derived from mark height)
Mark-to-type gap = 0.75x
Type aligns to mark vertical center
```

### Three Lockup Modes

| Mode | When | What shows |
|------|------|-----------|
| **Mark-only** | < 48px, favicon, roster density | Just the SVG mark |
| **Horizontal lockup** | 48-200px, cards, nav | Mark + name side by side |
| **Stacked lockup** | > 200px, hero, dossier, LED | Mark above, name below, descriptor under |

### The "X Unit" Rule

Clear space around any mark = the cap-height of one character in the construct's chosen font at its paired size. This is self-referencing — the mark's breathing room is defined by its own typography.

### Optical Weight Matching

The mark's stroke weight at display scale MUST match the optical weight of its paired font. From TDR-005:
- Basement Grotesque Bold at 160px → 1.5px stroke weight
- Lighter fonts (Söhne Leicht, Untitled Sans Light) → thinner strokes (1.0px)
- Heavier fonts (Druk, Knockout) → heavier strokes (2.0px)

## The Workflow — Mark → Type → Lockup

### Step 1: Generate Mark (Recraft V4 Pro)
Single-focus prompts per `construct-insignia-singles-v1.md`. Pick winner.

### Step 2: Identify Register
Match the construct's persona to a typography register from the table above.

### Step 3: Font Exploration
For each construct, explore 2-3 fonts within the mapped register:
- Set the construct name in each candidate font
- Test at three scales: 24px (card), 64px (detail), 200px+ (hero)
- Test alongside the mark at each scale

### Step 4: Optical Weight Calibration
Adjust mark stroke weight to match the chosen font's optical weight at display scale. The mark and type must feel like they belong to the same physical system.

### Step 5: Lockup Definition
Define the three lockup modes (mark-only, horizontal, stacked) with specific measurements derived from the "X unit" of the chosen font.

### Step 6: System Validation
All 23 construct lockups displayed together must:
- Feel like the same family (shared grid, shared void background, shared bone color)
- Each be instantly distinguishable (different mark, different type voice)
- Work at the glass case scale (catalog card) AND the LED billboard scale (hero)
