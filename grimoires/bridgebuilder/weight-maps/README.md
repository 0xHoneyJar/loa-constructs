## How to Read a Weight Map

Each map has:
- **weights** — 7 dimensions (domain, surface, motivation, affinity, attention, gravity, maintenance)
- **threads_detected** — composition opportunities with other subjects
- **notes** — context that doesn't fit the schema but matters

Threads follow 4 patterns:
1. **complementary_gap** — one's strength fills another's absence
2. **shape_affinity** — different problems, same architecture
3. **motivation_convergence** — reaching toward the same place from different starts
4. **attention_overlap** — reading the same signals through different lenses

## Three Forms of Composition (from thread-map.md)

1. **Structural** — edges in the dependency graph (observer↔crucible). Strongest coupling, highest fragility.
2. **Linguistic** — shared vocabulary without declared dependency (artisan's taste tokens). Medium coupling, high resilience.
3. **Cultural** — gravitational influence through ideas, not schemas (k-hole's depth philosophy). Lowest coupling, highest resilience.

The most resilient integrations are linguistic. The vocabulary IS the integration.
