## The Version-Surface Tangle (top governance gap)

Three release surfaces disagree:

```
README badge:      v2.41.0   (2026-05-09)  ← README.md:4
GitHub Release:    v2.43.0   (2026-05-09)  ← gh release list
git tag:           v2.50.4   (2026-06-30)  ← git tag --sort
```

The post-merge pipeline (`.github/workflows/post-merge.yml`; README.md:3 comment cites Issue #821 E) is supposed to keep badge + CHANGELOG in sync. It has not, for ~9 minor versions. Additionally README.md:11's inline version-surface map pins "loa-framework: v1.130.0" while `.loa-version.json` says 1.196.0.
