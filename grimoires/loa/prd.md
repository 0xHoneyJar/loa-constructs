## 1. Product overview

**[GROUNDED · `package.json:5`]** loa-constructs is "SaaS platform for distributing, licensing, and monetizing AI agent constructs."

**[GROUNDED · `README.md:13-19`]** A package distribution network for AI agent expertise. A construct is a self-contained pack — identity, skills, and boundaries — installed into a Claude Code session. After install, the agent can be invoked by slug, name, command, or persona handle. Multiple constructs can be composed into a pipeline with typed streams between stages.

**[GROUNDED · `README.md:137`]** This repo owns a narrow slice: distribution + registry API + license-verify hooks. UIs and ledger live in sibling repos.

## 4. Non-functional requirements

### 4.1 Reliability

**[GROUNDED]**
- Maintenance mode global middleware (`middleware/maintenance.ts`, app.ts:54) for migration cutovers
- Idempotent webhooks (delivery dedup table)
- Graceful shutdown (`apps/api/src/index.ts:41-58`, SIGTERM/SIGINT, 10s force-exit)
- Mock DB mode for local dev (`db/mock.ts`, refused in production via `config/env.ts:91`)

### 4.2 Security

**[GROUNDED]**
- JWT RS256 preferred, HS256 deprecated/legacy (`config/env.ts:51-60`)
- Production guard: JWT_SECRET ≥32 chars (`config/env.ts:118`)
- Security headers middleware (`middleware/security.ts`)
- CORS allowlist enforced in production only (app.ts:62-71)
- Rate limiting global + per-route (Redis-backed)
- Pack content hash integrity check
- Org gating via `CONSTRUCTS_ORG=0xHoneyJar` (cycle-038)

### 4.3 Observability

**[GROUNDED]**
- Pino structured logging (`lib/logger.ts`)
- Per-request UUID injection (`middleware/request-id.ts`)
- Sentry monitoring (`lib/monitoring.ts`)
- OpenAPI spec exposed at `/v1/docs/openapi.{json,yaml}` + Swagger UI

### 4.4 Performance

**[INFERRED]**
- Upstash Redis for rate-limit + caching
- R2 presigned URLs (avoid streaming through API)
- Drizzle prepared statements (typical Drizzle pattern, not exhaustively verified)
- VitePress static site generation (no SSR overhead for docs)
