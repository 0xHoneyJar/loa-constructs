### Stats handlers (NEW in T1.5 — not rewrite, authorship)

Per SDD §11.1 — atomic counter semantics. Use:
```ts
.update(packs).set({ view_count: sql`${packs.view_count} + 1` }).where(eq(packs.slug, slug))
```
No fetch-then-update. SQLite row-level atomicity inherited by libSQL.
